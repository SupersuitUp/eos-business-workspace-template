# Business Health Snapshots

Step-back diagnostics across all six EOS Components.

## Naming Convention

`YYYY-MM-DD-snapshot.md` per snapshot.

## When To Run

- Before every quarterly off-site (sets the agenda).
- Before the annual planning day (informs the 1-Year Plan refresh).
- Anytime the operator wants a step-back read.

## How to Add a Snapshot

Use the `eos-business-health-snapshot` skill. The skill reads `vto.md`, recent `meeting-notes/*.md`, `scorecards/*.md`, `rocks/*.md`, and `people-analyzer/*.md`, then scores each of the six Components 1-10 and identifies the top 3 priorities for the next quarter.
