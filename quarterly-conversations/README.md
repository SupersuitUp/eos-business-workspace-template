# Quarterly Conversations

Manager-direct-report 60-minute informal 1-on-1 every 90 days.

## Naming Convention

`<person-slug>-YYYY-MM-DD.md`

Examples:
- `alice-chen-2026-06-15.md`
- `bob-smith-2026-06-17.md`

## Cadence

Every 90 days, aligned to the quarterly off-site. Each manager has a Quarterly Conversation with each of their direct reports.

## Discipline

- **The conversation is the artifact.** This file is the manager's PREP BRIEF only. There is no formal write-up after the conversation. No HR file. No rating.
- **Two-way prompts:** "What's working?" and "What's not?" — both the direct report and the manager answer both.
- **Not a performance review.** Once it becomes formalized, it stops being a connection ritual.

## How to Add a Prep Brief

Use the `eos-quarterly-conversation-prep` skill, passing the direct report's name. The skill writes the brief here, ready for the manager to walk into the conversation prepared.
