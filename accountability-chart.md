# Accountability Chart

*The supercharged org chart. Every seat named, every seat's five major roles listed, every reporting line clear.*

---

> **How to use this file.** Every seat in the company, named with 5 major roles per seat. One person per seat. The Chart is updated whenever the org changes (new hire, new function, restructure, departure), not on a quarterly cadence. Update via the `eos-build-accountability-chart` skill.

## Adding More Seats

Add a new H2 section for each function head, individual contributor, or team. Always:

- 5 major roles per seat (not 3, not 9, five)
- One person per seat (split the seat or pick one if two people are sharing)
- Explicit reporting line (no dotted lines, no matrix)

If a seat is needed but unfilled, leave `[Name TBD]` and add a `**Planned hire:** [YYYY-MM]` line. If a seat is currently held by someone in another seat (founder doing operations), name them in both seats and add `**Plan:** Hire dedicated [seat name] by [YYYY-MM].`
