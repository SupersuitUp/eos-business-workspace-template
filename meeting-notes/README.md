# Meeting Notes

Weekly L10 meeting notes. One file per meeting, per scope.

## Naming Convention

`YYYY-MM-DD-<scope>-l10.md`

Examples:

- `2026-06-03-leadership-l10.md`, the leadership team's L10 on 2026-06-03.
- `2026-06-03-sales-l10.md`, the sales department's L10 on the same day.
- `2026-06-03-operations-l10.md`, the operations department's L10.

## How to Add a New L10 Note

Use the `eos-run-level-10` skill at the start of every L10. The skill copies `L10-TEMPLATE.md` to the dated file and fills it in live during the meeting.
