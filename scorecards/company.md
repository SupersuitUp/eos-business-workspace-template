# Company Scorecard

*5-15 weekly activity-based leading indicators with owners, goals, and 13 weeks of history.*

---

> **How to use this file.** 5-15 weekly activity-based leading indicators reviewed in the leadership L10 every week. Each metric has an owner, a weekly goal, and a 13-week rolling history. Cascade departmental scorecards from here. Update via the `eos-design-scorecard` skill (to add or refine metrics) and via `eos-run-level-10` (to record weekly readings).

## The Scorecard

Replace the example rows below with your real metrics. Pick LEADING indicators (the team can influence this week), not LAGGING ones (next quarter's revenue). Pick ACTIVITY-based metrics (calls made, demos booked) over OUTCOME-based metrics (deals closed).

| Metric | Owner | Goal | W1<br>YYYY-MM-DD | W2 | W3 | W4 | W5 | W6 | W7 | W8 | W9 | W10 | W11 | W12 | W13 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| [Outbound sales touches per week] | [Sales lead name] | ≥[150] | [actual] | | | | | | | | | | | | |
| [Discovery meetings booked per week] | [Sales lead name] | ≥[12] | | | | | | | | | | | | | |
| [New trial sign-ups per week] | [Marketing lead name] | ≥[25] | | | | | | | | | | | | | |
| [Median customer support response time (h)] | [Support lead name] | ≤[4] | | | | | | | | | | | | | |
| [Active users per week] | [Product lead name] | ≥[X] | | | | | | | | | | | | | |

**Reading convention:** each cell holds the actual value for that week. Mark with ✓ if at or above goal, ✗ if below. Off-track cells drop into the L10's Issues List for IDS.

**13-week rolling window:** when a new week begins, drop the oldest column off the right. This is the company's pulse over a quarter.
