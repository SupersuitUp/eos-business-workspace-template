# Rocks

Quarterly priorities. One file per quarter, naming `Q{YYYY}-{Q}.md` (e.g., `Q1-2026.md`, `Q2-2026.md`, `Q3-2026.md`, `Q4-2026.md`).

## How to Add a New Quarter

Use the `eos-set-quarterly-rocks` skill at the quarterly off-site (every 90 days). The skill writes the new quarter's file here. Each leader: 1-3 SMART personal Rocks cascading from 3-7 company Rocks cascading from the 1-Year Plan.

## The 80% Target

Aim for 80% completion of all set Rocks. 100% means the Rocks were too easy. Below 65% indicates either under-execution or unrealistic Rocks; IDS the root cause before setting next quarter's.

## SMART Criteria (non-negotiable)

- **Specific:** what exactly will be done.
- **Measurable:** how will we know it is done (a number, a status, a binary check).
- **Attainable:** plausibly doable in 90 days.
- **Realistic:** the owner has the time, budget, authority.
- **Timely:** specific quarter-end date.
